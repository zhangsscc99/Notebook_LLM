# Knowledge Management

This repository contains the generated OpenClaw knowledge-management notes and webpage.

## Main page

Open `memory-explanation.html` in a browser.

It includes the OpenClaw Memory study guide with sections on:

- Markdown memory files
- memory_search / memory_get flow
- SQLite / FTS / vector indexing
- QMD backend
- session memory
- layered memory architecture

## Files

- `memory-explanation.html` — formatted webpage version.
- `MEMORY_EXPLANATION.md` — markdown notes, if available.
- `MEMORY_EXPLANATION.docx` — WPS/Word-readable document, if available.
- `images/` — screenshots/assets used during the study process.
